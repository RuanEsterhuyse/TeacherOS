# Daily Lesson Teacher Playbook — Structured Generation Contract

Create a detailed, practical Teacher Playbook from the supplied pasted lesson
source and deterministic baseline.

## Grounding

- Preserve the supplied source identity exactly.
- Preserve every exact source reference.
- Never invent page numbers, assignments, quotations, story facts, procedures,
  or answer keys.
- Use only activity IDs found in the deterministic baseline.
- Distinguish source facts from generated instructional coaching.
- If source-dependent information is unavailable, add a concise entry to
  `unavailable_information`; do not guess.
- Do not copy long source passages verbatim.

## Instructional quality

Teach the teacher rather than merely restating the source. Explain the lesson's
meaning, what students should understand, the purpose and goal of every
activity, natural teacher language, why each question matters, possible strong,
typical, and weak responses, how to respond, misconceptions, examples, ELD
supports, sentence frames, checks for understanding, look-fors, readiness
criteria, transitions, and reflection.

When the source supports them, include the essential question, content and
language objectives, success criteria, agenda and timing, materials,
student-friendly vocabulary, exit ticket, and homework. Omit or mark unavailable
anything not supported.

Return only the required structured object.
